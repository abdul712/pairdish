**Created:** 2026-09-07, from premium-corpus analysis (target_sites.sqlite, read-only, bounded queries)

## 1. Corpus patterns (food_recipes segment, 312 sites, 1,577 sampled articles)

| Site | Pages | Winning pattern | What we replicate — improved |
|---|---|---|---|
| foodstruct.com | 4,255 | X-vs-Y nutrition comparison pages | Pairing-decision comparisons ("Butter vs olive oil for roasting vegetables") with our calculators embedded |
| dietmenus.com | 3,532 | diet-lens planning guides (keto/vegan/GF × meal planning) | Diet/occasion-lens pairing guides (high-protein sides, gluten-free pairing swaps) |
| amazingfoodmadeeasy.com | 2,043 | per-ingredient technique reference (times/temps per cut) | per-ingredient pairing reference pages (what pairs with X + why + ratios) |
| turntablekitchen.com | 473 | pairing-titled content at scale | confirms pairing-title demand; we add tools + data they lack |
| melaniecooks.com | 2,514 | practical home-cook how-tos | practical angle, plain language |

**Corpus SEO-AI guideline summary (from seo_ai_guidelines):** avoid commodity pages; add original value via calculators/checklists/original visuals/data; design for query fan-out (decision criteria, comparisons, examples, official citations, next steps). PairDish's edge: interactive pairing tools + pairing-ratio data + official-source citations — none of the corpus pairing sites have tools.

**Do NOT replicate:** word-game answer dumps (wordcookieanswer.com — high count but zero authority value), Russian/Armenian-language pages (foodstruct).

## 3. Content mix check (48 pieces)

- Guides/how-tos (A,B,C,F,G guides): ~28 → 58% (within "~40%+"; guide family dominates but each is a distinct format: Q&A pairing, reference, framework, rescue)
- Tools (E): 4 → 8%
- Comparisons (D): 4 → 8%
- Listicles: 0 standalone; pairing guides are structured Q&A guides, not "10 best" listicles → listicle share <10% ✅ (rule: <30%)
- Explainers: 8 → 17%

## 4. Article spec (every piece)

- 1,200–1,900 words (tools pages shorter, 600–900)
- Meta description ≤160 chars
- REAL images only: Wikimedia Commons CC0/CC BY/CC BY-SA with attribution + credit log; never reuse a photo across articles; visual verification before scheduling
- Internal links: 3–8 per article (tools + related articles)
- External links: 2–5 official only (USDA FoodData Central, MyPlate, FDA, extension.edu, Cornell, etc.)
- NO FAQ sections (user rule)
- Natural persona, 2026-quality design, no listicle-only drift

## 5. Review-first execution plan

- **Batch A items 1–3 drafted now (run 1)** → live URLs for user review → PAUSE
- After user OK: 1/day cadence for the rest of Batch A, then B, then C…
- Every article: sitemap entry + articles-index card + internal links from 2 older articles + Bing URL submission (API works: 1,000/day quota)
- GSC re-crawl: via sitemap + internal links until `indexing` OAuth scope is granted
